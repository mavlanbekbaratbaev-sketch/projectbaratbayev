# Умный дом: проектирование локальной сети

Курсовая работа. Интерактивный сайт-демонстрация проекта ЛВС для системы «умный дом».

## Что внутри
- **Управление** — дашборд с устройствами, сценами, автоправилами и журналом MQTT-событий.
- **Схема сети** — кликабельная топология (роутер, коммутаторы, PoE, Zigbee-хаб, NAS, ИБП, VPN, резерв 4G).
- **VLAN и адресация** — таблица VLAN, правила ACL, калькулятор подсети.
- **Оборудование и протоколы** — используемое оборудование, протоколы, автоматизация, безопасность.

## Структура
- `index.html` — разметка страницы
- `style.css` — стили (светлая и тёмная темы)
- `script.js` — логика: устройства, сцены, схема сети, калькулятор
